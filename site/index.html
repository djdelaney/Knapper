Open-source MCP server for Obsidian

Let AI agents into your Obsidian vault without losing a note.

Knapper is a self-hosted MCP server that gives Claude and other agents read and write access to your Obsidian vault. Every write is checked, nothing gets overwritten blind, and anything unsafe stops instead of guessing.

The problem

Whoever saves last wins.

Give a few agents access to your vault (Claude on your laptop, Claude Code on another machine, Claude on your phone) and they all edit the same files through Sync. Edits vanish quietly, and nobody tells you.

How it works

One careful door into your vault.

You keep using Obsidian and Obsidian Sync. Knapper runs next to a synced copy of your vault, and agents talk only to Knapper. Many agents editing at once becomes one server handling one change per note at a time.

No blind overwrites

An edit that hasn't seen the latest version doesn't land.

Every edit carries a fingerprint of the version the agent read. If the note changed in the meantime, the edit is refused, the agent re-reads, and it tries again. There is no "just overwrite it" tool to misuse.

What that looks like in a chat

The agent gets an error and re-reads. You see one extra tool call, not a lost paragraph. Fingerprints are SHA-256 hashes of the note, shortened here.

Inside that save

The fingerprint check is one step of ten.

Every change follows the same path, in the same order. The other nine steps make sure what lands is whole, checked on disk, and logged. Two checks can stop the write, and when they do, nothing touches the disk. Hover or focus a step for what it does.

Stops instead of guessing

When Sync is unsure, writes wait for you.

When Obsidian Sync creates a conflict copy, or sync stops working, Knapper blocks writes to the affected notes until a human sorts it out. Agents never pick a winner. Reading keeps working the whole time.

Search you can trust

"No results" means it looked everywhere.

Search is built on ripgrep and every answer says how complete it is. truncated: false means every file in scope was searched. If results are cut off, a cursor picks up exactly where they stopped, with nothing skipped or repeated.

  • 1truncated: false means the whole scope was searched.
  • 2nextCursor resumes a cut-off search exactly where it stopped.
  • 3scannedFiles is how many files were actually searched.
  • 4totalMatches is counted, or null if it wasn't. Never estimated.

Your conventions

Archived folders

Files can be added to an archive, but nothing already in it can be changed.

Exact file transfers

Byte for byte, without the model in the middle.

Need a PDF or image byte for byte? The agent asks Knapper for a one-time link, its shell downloads the file with curl, and the hash is checked before the file lands. Uploads pass the same checks as any other write, plus a scan for leaked secrets. Off by default.

Security

This vault holds your whole life. It's treated that way.

Your vault never listens on your network. Agents reach it through a Cloudflare Tunnel behind Cloudflare Access, and Knapper checks the Access token again itself, so a mistake at the edge doesn't expose your notes. Paths are confined to the vault. Every action is logged with who made it. A read-only mode lets you start cautiously.

Tips for fast agents · optional

The round trip is the cost. Batch.

Knapper does about 12 ms of work per call. The round trip through the chat app is about 3 seconds. So agents that batch reads and writes feel fast, and Knapper tells them to.

Get started

An honest path in. Trust it a step at a time.

01

Try it locally

Generate a sample vault and connect Claude Code. Nothing real involved.

02

Deploy read-only

Point it at your vault with Mcp__ReadOnly=true. Agents can look but not touch.

03

Turn on writes

Run knapper verify against your deployment. When it passes and you trust it, turn read-only off.

To try it
  • macOS or Linux
  • .NET 10 SDK, ripgrep 15+, git
To deploy it
  • A Linux host with a case-sensitive filesystem
  • Obsidian Sync subscription, with obsidian-headless
  • Cloudflare Tunnel and Access
